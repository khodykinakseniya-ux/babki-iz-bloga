# БАБКИ ИЗ БЛОГА

Отдельный лендинг, не зависит от сайта «ИИ-ЗАПУСК».

Node.js 24, npm. `npm ci`, `npm run dev -- --host 0.0.0.0`. Сборка: `npm run build`. Локальная проверка сборки: `npm run preview -- --host 0.0.0.0`.

## GitHub Pages

`.github/workflows/deploy.yml` автоматически собирает ветку `main` и публикует **только `dist`** через GitHub Actions. В Settings → Pages источник должен быть GitHub Actions. Workflow требует `contents: read`, `pages: write`, `id-token: write`; отдельные секреты не нужны. Ручной запуск доступен через Actions → Deploy GitHub Pages → Run workflow.

Адрес публикации: https://khodykinakseniya-ux.github.io/babki-iz-bloga/ . `vite.config.js` задаёт production base `/babki-iz-bloga/`, динамические фото и отзывы используют `import.meta.env.BASE_URL`. Статус публикации проверяется в Actions; наличие файлов в Git само по себе не означает успешный deploy.

После сборки `npm test` проверяет dev-версию и готовую production-сборку с префиксом Pages: загрузку CSS, шрифтов и всех оригинальных изображений, отсутствие горизонтального скролла и сенсорный свайп карусели. Системный Chromium требуется локально; workflow публикации запускает сборку без браузерных тестов.

## Материалы перед публикацией

Настройки в `src/config.js`: ссылка оплаты, юридические документы, данные ИП и оригинальные изображения. Фото Надежды, скриншоты отзывов Дарьи и Анисьи и изображение кейса Евгении извлечены без изменения из предоставленного PDF и подключены. CTA ведёт на https://payform.ru/aecRmSc/. Предоставленные оферта и политика размещены целиком в `public/legal/offer.html` и `public/legal/privacy.html`; исходные DOCX сохранены рядом. Реквизиты и официальный контакт взяты из документов. Генератор `python3 scripts/render-legal.py` сохраняет исходные абзацы, переносы и нумерацию без редактирования текста. Проверка в `tests/legal.spec.js` сравнивает весь текст HTML с DOCX. В документах сохранены указания владельцу проверить НДС, сторонние сервисы и процессы обработки данных; размещение не означает юридическую экспертизу. Тексты и порядок секций сохранены при оформлении. Стили и локальные шрифты подключены напрямую из HTML и загружаются независимо от JavaScript.

Шрифты Dela Gothic One и Montserrat поставляются локально через npm, внешние сервисы шрифтов не нужны. Слайдер использует нативный горизонтальный скролл со scroll-snap; поддерживает свайп, стрелки и клавиатуру, открытие оригинала в dialog. Автопрокрутки нет.

Проверки: `npm test` использует системный `/usr/bin/chromium` (можно переопределить `CHROMIUM_PATH`). Превью после проверок сохраняются в `previews/`. Проверки карусели выполняются с реальными скриншотами; проверяется свайп, стрелки, клавиатура и увеличение. Отдельный тест проверяет загрузку оформления без JavaScript. Шрифт символов DejaVu Sans распространяется по лицензии в `public/assets/symbols-LICENSE.txt`.
