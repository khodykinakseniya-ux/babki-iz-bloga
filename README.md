# БАБКИ ИЗ БЛОГА

Отдельный лендинг, не зависит от сайта «ИИ-ЗАПУСК».

Node.js 24, npm. `npm ci`, `npm run dev -- --host 0.0.0.0`. Сборка: `npm run build`. Локальная проверка сборки: `npm run preview -- --host 0.0.0.0`.

## Материалы перед публикацией

Настройки в `src/config.js`: ссылка оплаты, юридические документы, данные ИП и оригинальные изображения. Фото Надежды, скриншоты отзывов Дарьи и Анисьи и изображение кейса Евгении извлечены без изменения из предоставленного PDF и подключены. CTA ведёт на https://payform.ru/aecRmSc/. До публикации добавить настоящие оферту, политику и реквизиты ИП; отсутствующие ссылки не имитируются. Тексты и порядок секций сохранены при оформлении. Стили и локальные шрифты подключены напрямую из HTML и загружаются независимо от JavaScript.

Шрифты Dela Gothic One и Montserrat поставляются локально через npm, внешние сервисы шрифтов не нужны. Слайдер использует нативный горизонтальный скролл со scroll-snap; поддерживает свайп, стрелки и клавиатуру, открытие оригинала в dialog. Автопрокрутки нет.

Проверки: `npm test` использует системный `/usr/bin/chromium` (можно переопределить `CHROMIUM_PATH`). Превью после проверок сохраняются в `previews/`. Проверки карусели выполняются с реальными скриншотами; проверяется свайп, стрелки, клавиатура и увеличение. Отдельный тест проверяет загрузку оформления без JavaScript. Шрифт символов DejaVu Sans распространяется по лицензии в `public/assets/symbols-LICENSE.txt`.
